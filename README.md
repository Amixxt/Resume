# Interactive Web Resume

Ek clean, modern aur professional web-based resume template jise aap direct Google Antigravity IDE ya kisi bhi web previewer me edit kar sakte hain.

## 📁 File Structure
- `index.html` : Resume ka core layout aur content.
- `style.css` : Modern styling, dark sidebar, responsive grid aur typography.

## 🚀 Quick Steps for GitHub & Google Antigravity:
1. GitHub par ek nayi repo banayein: `my-resume`.
2. Ye saari files repo me push karein.
3. Google Antigravity IDE me `Clone Repository` karke repo ka link daalein.
4. Antigravity ke live code editor me changes karein aur direct commit karein!
