# Automatic Git Commit and Push Rule

## Instructions
- Har task complete hone ke turant baad (jaise hi code ya file me changes ho jayein):
  1. Modified files ko stage karein (`git add .`)
  2. Ek descriptive commit message ke sath commit karein (`git commit -m "<task description>"`)
  3. Changes ko automatically GitHub remote branch par push karein (`git push origin main`)
- User ko har bar manual `git push` bolne ki zaroorat nahi padni chahiye. Har step/task complete hote hi auto push execute karein.
